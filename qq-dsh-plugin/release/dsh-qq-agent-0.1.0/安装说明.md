# dsh-qq-agent 安装说明

给你的电脑端 QQ 装一个会自己聊天的角色。它跑在 **DeepSeek Harness（DSH）** 里，
用的是你 DSH 里已经配好的模型，不需要另外买 API。

---

## 先确认三件事

缺任何一样，插件都能装上，但不会真正开始回话。

### 1. DSH 是桌面版，而且能正常聊天

打开 DeepSeek Harness，随便发一句话，能收到回复就算通过。

### 2. 电脑端 QQ 已经装了 NapCat（或 LLOneBot）

插件通过 **OneBot 11** 跟 QQ 说话，不是直接操作 QQ。你需要：

- QQ 已经是「注入 NapCat」的状态（一般是装 NapCat 一键包，从它的启动器开 QQ）
- NapCat 里开了 **WebSocket 服务端**，端口默认 `3001`

自检：浏览器打开 `http://127.0.0.1:3000/get_login_info`，能看到自己的 QQ 号和昵称就是通了。
（打不开 `3000` 也没关系，只要 WS 的 `3001` 开着就行。）

### 3. 知道自己的 QQ 号，和想授权的群号

群号可以在 QQ 群的「群资料」里看到。

---

## 装

1. 把整个文件夹放到一个**不会被随手删掉**的地方，例如
   `D:\dsh-qq-agent`。**不要**放在压缩包里直接双击运行。
2. 双击 **`安装.cmd`**。
3. 看到「装好了」之后，**关掉 DeepSeek Harness，再重新打开**。

> 为什么要重启：DSH 只在启动时加载插件的主机端代码。装完不重启，左栏不会出现 QQ 图标。

安装脚本会自动做这些事，你不需要手工改任何文件：

- 把插件复制到 `%USERPROFILE%\.dsh\plugins\dsh-qq-agent`
- 在 DSH 的 profile 里登记依赖和加载顺序
- 用 DSH 自带的 pnpm 把它装进 `node_modules`
- 备份改动前的 `package.json`（同目录 `.bak-时间戳`）

**只有命令行也能装：**

```
node tools\install.mjs                 :: 自动找 DSH、自动挑 profile
node tools\install.mjs --profile web   :: 指定 profile
node tools\install.mjs --dry-run       :: 只看要做什么，不改文件
node tools\install.mjs --uninstall     :: 卸载
```

## 第一次配置

重启后，左侧栏会出现一个 **QQ 图标**，点进去。

按顺序填这四块，填完点右上角「保存」：

### 主人与人设

- **主人 QQ 号**：填你自己的号。主动搭话时会优先找你，管理指令也只有你能用。
- **人格提示词**：一段话说明她是谁、怎么说话。不想自己想就点下面的预设
  （鲸鱼娘 / 猫娘小满 / 管家先生 / 傲娇学妹 / 技术大佬 / 普通朋友）。

### 连接

- **WebSocket 地址**：默认 `ws://127.0.0.1:3001`，跟 NapCat 里的一致就行。
- 如果 NapCat 设了 token，填进「令牌」。
- 点 **「拉取群列表」**，能看到你的群就说明连上了。

### 回复

- **群聊触发方式**：建议先留 `@ 我才回`，观察一阵再放开。
- **授权群号**：从上面拉到的群列表里点「加入白名单」，或者手工填群号。**没在名单里的群，它一句都不会回。**
- **私聊**：默认只回白名单里的人。把朋友加进「私聊白名单」，或者关掉「仅白名单」。
- **主动发言**：喜欢它自己来找你说话就开着。默认 40~150 分钟一次，凌晨 2~8 点不打扰。

### 能力

- **联网**：`自动` 就够用（遇到需要查的东西才搜）。
- **看图**：如果你的聊天模型看不了图，这里会提示。把「识图 Provider」选成标着
  「（可看图）」的那个即可。
- **语音**：想要语音回复再开。第一次用点一下「试听」，能听到声音就说明通了。

## 用起来

装完就可以正常聊了。在授权群里 @ 她，或者私聊她。

她也能听懂这些指令（**只有主人和 `admin.uins` 里的人能用**）：

| 指令 | 作用 |
| --- | --- |
| `.help` | 看所有指令 |
| `.status` | 看运行状态 |
| `.pause` / `.resume` | 暂停 / 恢复自动回复 |
| `.persona <文本>` | 临时改人设 |
| `.say <文本>` | 让她原样说一句 |
| `.bili` | 请求刷一轮 B 站（要主人批准） |
| `.videos` | 看暂存了哪些视频 |
| `.reset` | 清空这个会话的记忆 |

## 常见问题

**装完了，左栏没有 QQ 图标**

1. 确认真的重启了 DSH（不是只关了窗口到托盘里）。
2. 在插件目录里跑一次 `node tools\install.mjs --dry-run`，看它找的 profile 是不是你在用的那个。
3. 装了多个 profile（比如 `desktop` 和 `web`）时，别装错：加 `--profile desktop` 再装一次。

**面板能打开，但「拉取群列表」报错**

说明 DSH 里插件活着，但没连上 NapCat。逐项排查：

- NapCat 的 WebSocket 服务端开了吗？端口是 `3001` 吗？
- 地址写成 `ws://127.0.0.1:3001`（不要 `wss://`，不要漏 `ws://`）。
- NapCat 设了 token 的话，插件里也要填一样的。

**它不回话**

按顺序看「日志」页：

- 显示 `未授权`：群号或私聊白名单没配对。
- 显示 `not-mentioned`：群里没 @ 她，而触发方式是「@ 我才回」。
- 显示 `模型返回了空内容`：去「能力 → 模型路由」换一个模型，或把 Max Tokens 调到 1600 以上。
- 显示连接正常、日志也有「回复」记录：那是发成功了，检查 QQ 那边是不是被折叠了。

**主动发言一直没出现**

默认间隔 40~150 分钟，而且凌晨不打扰，还会受「每小时上限」约束。
想立刻验证，去「总览」页看「下一次主动发言」的倒计时，或临时把间隔改成 1~5 分钟。

**语音发出去是文件不是语音条**

NapCat 版本太老。4.18 以上实测直接接受 MP3；老版本可能要求 SILK。

## 数据存在哪

都在 `%USERPROFILE%\.dsh\qq-agent\`：

- `config.json` —— 全部设置
- `videos.json` —— 看过的 B 站视频（默认 2 小时过期）

想换位置，设环境变量 `DSH_QQ_AGENT_DATA` 指向别的目录。

**卸载**只删插件，不动这个目录。想彻底清掉就手动删掉它。

---

## 隐私

- 配置和视频书架只在本机。
- 对话会发给你在 DSH 里选的那个模型，和正常用 DSH 聊天没区别。
- 语音合成会把**要朗读的那段文字**发到 `fanyi.baidu.com` 的公开 TTS 接口。介意就把语音关掉。
- `src/net.cjs` 在遇到本机 TLS 中间人代理时会用 `rejectUnauthorized:false` 重试，
  只用于访问 B 站、Bing、百度这几个公开接口。

---

## 卸载

双击 **`卸载.cmd`**，然后重启 DSH。
